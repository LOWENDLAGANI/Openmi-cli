CLI Installation

Get started with Openmi

Install the Openmi CLI in seconds on Windows, Linux, macOS, or Android Termux. No IDE plugin required.

1 Open your terminal

Press Ctrl + ` (or Cmd + J on macOS) to open the integrated terminal in VS Code.

2 Navigate to your project directory

>_ cd /path/to/your-repo

3 Install Openmi

>_ npm install -g openmi

Requires Node.js ≥ 16. Automatically selects the native binary for your platform.

>_ curl -fsSL https://raw.githubusercontent.com/LOWENDLAGANI/Openmi-cli/main/install.sh | sh

Installs the native binary on Linux (x64 / arm64), macOS (Apple Silicon), and Android Termux (aarch64).

PS> irm https://raw.githubusercontent.com/LOWENDLAGANI/Openmi-cli/main/install.ps1 | iex

Run in PowerShell on Windows x64. Downloads and adds openmi.exe to your user PATH.

>_ cargo build -p openmi-cli --release

Clone LOWENDLAGANI/Openmi-cli and run ./target/release/openmi smoke-test to verify.

4 Sign in & run Openmi

>_ openmi login
>_ openmi

openmi login uses device-code pairing (works over SSH and headless boxes). Approve the code at /verify, then run openmi.

Automatic updates

On launch, Openmi checks GitHub Releases with a 3-second timeout, verifies the SHA-256 checksum, and updates seamlessly.

  • Check manually: openmi update --check
  • Disable auto-check: OPENMI_NO_AUTO_UPDATE=1

Handy first commands

Once installed, you can run interactively or script Openmi from your shell.

  • openmi --resume — continue your latest repo session
  • openmi run "explain src/main.rs" --permission read-only
  • openmi credits · openmi models · openmi whoami
