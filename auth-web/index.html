Built for the CLI

Everything you need in one fast native binary.

No bloated editor lock-in. Openmi runs directly in your shell with strict workspace safety, instant rollbacks, and flexible billing.

TUI + Headless

Interactive TUI & scriptable CI

Work interactively in a crisp ratatui interface with /plan, @path completion, and session resume, or run headlessly with openmi run --json.

Checkpoints

Exact-byte /diff & /undo

Pre-write snapshots preserve exact bytes including UTF-8 BOM and CRLF endings. Inspect changes inline and roll back any file or run instantly.

PathGuard

Workspace sandboxing & modes

Cycle between read-only, ask, and trusted modes with Shift+Tab. Symlink and O_NOFOLLOW guards keep edits inside your repo.

Cross-Platform

Desktop, SSH & Android Termux

Ships for Windows, Linux, macOS, and Termux (aarch64) with rustls-only TLS (zero OpenSSL) and SHA-256 verified auto-updates.

Extensible

MCP servers & project guides

Connect stdio MCP tools globally or per-repo in .openmi/mcp.json, and load instructions automatically from OPENMI.md, CLAUDE.md, or AGENTS.md.

Flexible Access

Managed credits or BYOK

Start immediately with free daily credits, grab an hourly pass when shipping hard, or connect your own provider API keys on Providers (BYOK).

Quickstart

From zero to coding in 30 seconds.

01

Install the CLI

Install globally with npm, or use our one-line shell / PowerShell installers.

npm install -g openmi
02

Pair your terminal

Device-code login works locally, over SSH, and inside Termux with zero API key setup.

openmi login
03

Launch in your repo

Open any project directory and start prompting. Resume anytime with --resume.

openmi

Start free. Scale with hourly passes or BYOK.
