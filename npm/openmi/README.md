# Openmi CLI

AI coding assistant in your terminal.

## Install

```bash
npm install -g openmi
```

## Quick Start

```bash
openmi login
openmi
```

## Supported Platforms

Prebuilt binaries are automatically installed for:
- Linux (`x64`, `arm64`)
- macOS Apple Silicon (`arm64`)
- Windows (`x64`)

For shell/PowerShell installers or manual downloads, see [openmi-release](https://github.com/LOWENDLAGANI/openmi-release).
